# Cobertura del catálogo

Las 39 fichas especifican variables, unidades, fuentes declaradas y resultados. Las plantillas se exportan con los valores editables en blanco. Las comprobaciones usan datos sintéticos.

| Ficha | Cálculo demostrativo |
|---|---|
| Viga | Momento por carga uniforme y momento nominal requerido |
| Losa | Relación entre luces |
| Zapatas | Presión neta del terreno y área preliminar |
| Muro de gravedad | Longitud de zapata y altura de suelo activa |
| Muro TEM | Coeficiente de empuje activo |
| Canales | Geometría, radio hidráulico, velocidad y caudal |
| Impulsión | Altura manométrica y potencia |
| Conducción por gravedad | Velocidad y alturas de presión |

Las fichas restantes registran los resultados aportados por el elaborador. La revisión y aprobación técnicas corresponden a sus respectivos perfiles.
